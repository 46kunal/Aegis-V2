# Aegis V2

Project scaffold for the Aegis V2 digital twin platform.

## Structure

- `frontend/` for the client application
- `backend/` for the FastAPI service layer
- `docker-compose.yml` for local infrastructure

## Backend

The backend currently includes a minimal health check at `GET /health`.
